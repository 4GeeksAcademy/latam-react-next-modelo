# Contexto del proyecto

## Descripcion
Este proyecto es una aplicacion web enfocada en brindar informacion del Mundial 2026. La idea principal es ofrecer una experiencia clara y organizada para consultar partidos, fechas y resultados del torneo.

## Stack tecnologico
- Next.js 16
- React 19
- TypeScript 5
- Tailwind CSS 4
- ESLint 9

## Funcionalidad principal
La web debe incluir:
- Informacion general del Mundial 2026.
- Fixture completo del torneo.
- Fechas de los partidos.
- Resultados de cada encuentro.

## Objetivo
Construir una plataforma sencilla, moderna y mantenible para seguir el Mundial 2026, con foco en fixture, fechas y resultados actualizados.

# Resumen de diseño visual
El diseño es minimalista, inspirado en la bandera argentina: fondo de tres franjas horizontales (celeste, blanco, celeste), tipografía grande y moderna, paleta celeste/blanco, componentes con bordes suaves y layout aireado. El foco es la claridad y la accesibilidad visual, con contraste alto y pocos elementos decorativos.
